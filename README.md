# Bruschetta by Food Cabaret — Premium Café Website

A tailored, editorial multi-page café website concept for **Bruschetta by Food Cabaret**, located on The Concourse inside the historic **Leeds Corn Exchange**, Call Lane, Leeds, United Kingdom.

---

## 🏛️ About the Project

This project demonstrates a contemporary, conversion-focused online presence for an independent specialty coffee shop and eatery.

- **Location:** The Concourse, Leeds Corn Exchange, Call Lane, Leeds LS1 7BR
- **Identity:** Specialty coffee, handmade pastries, French toast (Pain Perdu), Algerian m'hajeb crêpes, Tunisian chakchouka, and Mediterranean savoury bruschettas.
- **Photography:** 100% authentic business photographs mapped directly to their actual menu subjects. Zero AI-generated food or stock imagery.

---

## 🚀 Pages Included

1. **Homepage (`/`)**: Hero under the iconic Leeds Corn Exchange rotunda, trust strip, 6 signature dish showcases, brand introduction, interactive menu category navigator, dark editorial feature on global flavours, drinks showcase, Placejoys reviews preview, location/hours strip, and final conversion CTA.
2. **About Our Café (`/about`)**: Story of the café's culinary approach, coffee culture, viennoiserie, brunch plates, and atmospheric dining under the historic domed roof.
3. **Full Menu (`/menu`)**: All 15 menu categories (Categories A–O), live search filtering across titles and descriptions, category jump pills, type filters (Food/Drinks/Extras), dietary indicators (`(V)`, `(Ve)`), allergen notices, and direct link to official online ordering.
4. **Signature Specialties (`/specialties`)**: Deep dive into the warmed Pistachio Croissant, Croque-Madame & morning grills, La Haine (Algerian hotdog) & m'hajeb crêpes, espresso bar rituals, and a curated photo gallery.
5. **Why Visit Us (`/why-visit`)**: Value proposition of choosing Bruschetta: distinctive international flavours, tranquil natural light on the concourse, verified patron feedback, and convenient city-centre arrival.
6. **Customer Reviews (`/reviews`)**: Transparent presentation of 4.5/5 score (291 reviews) from Placejoys evidence, verified testimonials from named reviewers (Vivienne Li, Y T, Amin NSJ, Robert, Raya Verdi, Ss), and pre-publication verification notices.
7. **Location & Contact (`/contact`)**: Physical Corn Exchange address, weekly opening hours schedule (with verification disclaimer), tested Google Maps directions link, official email (`foodcabaret@gmail.com`), verified social profiles, official online ordering link, and factual FAQ accordion.
8. **Privacy Information (`/privacy`)**: Concept demonstration notice, zero tracking cookies / advertising pixels, third-party link disclaimers, and contact handling.
9. **Sitemap (`/sitemap.xml`) & Robots (`/robots.txt`)**: Search engine optimization metadata.

---

## 🛠️ Tech Stack

- **Framework:** Next.js 16 (App Router)
- **UI & Styling:** React 19, Tailwind CSS v4
- **Typography:** Cormorant Garamond & Manrope (via `next/font/google`)
- **Icons:** Lucide React & custom SVG social brand icons
- **Language:** TypeScript

---

## 💻 Getting Started Locally

```bash
# 1. Install dependencies
npm install

# 2. Run development server
npm run dev

# 3. Build for production
npm run build

# 4. Start production server
npm start
```

Visit [http://localhost:3000](http://localhost:3000) to view the website.
